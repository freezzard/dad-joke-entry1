Entry for the make.fun bounty **Dad Joke Showdown**. `main.ts` runs a local round-robin tournament over nine original dad joke candidates, scoring each on the judge brief — clean pun, groan, flat delivery, freshness, tightness, spoken rhythm — and writes the winning line (74 characters) to `/output/entry.txt`. The pick is deterministic: every run writes byte-identical output.

The winning joke: a sourdough starter, asked how it is doing, answers that it is on the rise.

## Run it

```sh
node main.ts
```
